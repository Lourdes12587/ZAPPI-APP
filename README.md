# El Gordo Zappi — Carta online con carrito

Landing page y carta online para una pizzería y hamburguesería: el cliente filtra por categorías, añade productos al carrito y confirma el pedido. Hecha con JavaScript puro, sin frameworks.

**Demo:** https://zappi-app.vercel.app/

## Funcionalidades

- Productos generados dinámicamente desde JavaScript a partir de un array de datos
- Filtros por categoría con estado activo
- Sección de recomendados
- Carrito de compras: añadir, sumar o restar unidades, eliminar productos y total actualizado al momento
- El carrito se guarda en **localStorage** y se mantiene al recargar la página
- Formulario de pedido con número de pedido, aviso de confirmación y vaciado del carrito
- Diseño adaptable a móvil

## Tecnologías

HTML5 · CSS3 · JavaScript (ES6+) · localStorage · Vercel

## Estructura

```
index.html   maquetación
index.css    estilos
date.js      datos de productos y categorías
main.js      renderizado, filtros y lógica del carrito
```

## Puesta en marcha

No necesita instalación: abre `index.html` en el navegador o usa la extensión Live Server.
